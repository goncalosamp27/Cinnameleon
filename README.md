# Cinnameleon

A lightweight theme profile manager for Linux Mint Cinnamon.

Cinnameleon synchronizes complete desktop appearance profiles with the
current wallpaper.

## Planned features

- YAML-based theme profiles
- GTK, Cinnamon, icon and cursor themes
- Fonts and window borders
- Wallpaper synchronization
- Dark and light modes
- Native Cinnamon tray integration
- Event-driven operation without polling
